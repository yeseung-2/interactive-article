모바일/PWA 배포 안내

1. 이 ZIP의 모든 파일과 폴더를 기존 기사 배포 디렉터리에 상대경로를 유지하여 덮어쓰세요. 기존의 다른 파일은 삭제하지 마세요.
2. index.html, sw.js, manifest.webmanifest, frames/, assets/icons/, assets/media/가 함께 있어야 합니다.
3. HTTPS에서 배포해야 서비스 워커가 동작합니다. 기존 배포 URL과 같은 경로에 배포하세요.
4. 수정된 HTML은 브라우저에서 먼저 읽히고, iframe과 이미지는 개별 HTTP 요청으로 가져옵니다. 네트워크 그래프의 외부 CDN 라이브러리는 기존대로 유지됩니다.
5. 기존 서비스 워커/매니페스트 원본은 제공되지 않아 새 설정으로 구성했습니다. 기사 캐시 업데이트는 온라인 우선이며, 오래된 앱 탭을 닫고 다시 열면 새 서비스 워커가 활성화됩니다.
6. 오프라인에서는 방문 시 캐시된 파일만 사용합니다. 외부 CDN과 아직 방문하지 않은 인터랙티브 영역은 제한될 수 있습니다.
7. 실제 iOS Safari, Android Chrome, 배포 서버의 헤더 및 서비스 워커 등록은 배포 후 확인이 필요합니다.
